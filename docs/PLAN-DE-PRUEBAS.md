# Plan público de pruebas

Este repositorio prueba el comando:

```text
sabiparche github bootstrap ESPECIFICACION.toml
```

Contratos comprobados:

- autenticación mediante la GitHub App instalada;
- creación o verificación del repositorio remoto;
- identidad exacta de propietario y repositorio;
- visibilidad pública;
- generación de archivos y carpetas;
- creación de commits y ramas;
- publicación remota;
- segunda ejecución idempotente;
- compilación y tests del proyecto;
- journal local con evidencia.
